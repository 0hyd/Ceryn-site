引入

Go 没有 class 也没有构造函数关键字，但创建结构体实例时经常需要做初始化——设置默认值、校验参数、初始化内部字段。Go 社区约定用 New 开头的函数来完成这些工作，形成了统一的构造函数模式。

正文

定义

定义

构造函数模式是 Go 社区约定的对象初始化方式。Go 没有内置构造函数，而是通过 New 开头的普通函数来创建并初始化类型的实例。这种模式也叫工厂模式，调用方不需要了解内部细节，拿到手的就是一个可用的实例。

语法

例子

基本 New 函数

NewUser 封装了创建逻辑，调用方不用关心 User 的字段细节。

带默认值

构造函数里设好默认值，调用方只传必要的参数。

带错误返回

初始化可能失败时，返回 (*类型, error)，这是 Go 标准的错误处理模式。

带内部初始化

map、slice、channel 等需要 make 初始化的字段，在构造函数里处理好，避免调用方拿到 nil。

多种构造方式

没有函数重载，就用不同名字的 New 函数提供多种构造方式。

Options 模式

参数多时用 Options 模式，每个可选参数是一个函数，灵活且可扩展。

常见写法

写法说明
func NewUser() *User基本构造函数
func NewServer(addr string) (*Server, error)带错误返回
func NewConfig(host string) *Config带默认值
func NewCache() *Cache带内部初始化
func NewXxx(opts …Option) *XxxOptions 模式
func NewXxxWithLevel(l string) *Xxx多种构造方式

特点

  • Go 没有构造函数关键字，用 New 开头的普通函数代替
  • 构造函数通常返回指针 *类型
  • 初始化可能失败时返回 (*类型, error)
  • 内部需要 make 的字段（map、channel 等）在构造函数里初始化
  • 没有函数重载，用不同函数名区分多种构造方式
  • Options 模式适合参数多、可选参数多的场景
  • 构造函数是社区约定，不是语言特性，但几乎所有 Go 项目都遵循

理解

Go 用简单的 New 函数替代了其他语言的构造函数，看起来朴素但够用。好处是初始化逻辑就是一个普通函数，容易测试、容易理解。记住在构造函数里处理好默认值和需要 make 的字段，调用方拿到的就是一个随时可用的实例。

引出

构造函数创建实例，方法绑定行为，那怎么让不同类型有统一的”能力描述”？这就是 Go 接口 的作用——定义一组方法签名，任何实现了这些方法的类型都算实现了这个接口。
