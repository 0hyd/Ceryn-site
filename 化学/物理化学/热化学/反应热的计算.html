反应热的计算

2026年9月12日5分钟阅读

活跃分钟 0访问量 0点赞量 0点击量 0

  • 热化学计算

引入

知道反应会放热或吸热还不够，很多时候需要定量计算：燃料燃烧能释放多少热量？合成反应需要输入多少能量？新反应的反应热无法直接测量时怎么办？

这些问题推动了反应热计算方法的发展。

盖斯定律

定义

化学反应的反应热只与反应的始态和终态有关，与反应途径无关。

这意味着：反应热具有加和性。

如果一个反应可以分步进行，总反应热等于各步反应热之和：

ΔH总​=ΔH1​+ΔH2​+⋯+ΔHn​

应用场景

  • 目标反应难以直接测量反应热。
  • 已知相关反应的反应热数据。
  • 通过已知反应组合出目标反应。

使用方法

  1. 找出已知反应热的相关反应。
  2. 将这些反应适当调整（反向、倍乘）。
  3. 相加得到目标反应。
  4. 对应的反应热也相应调整后相加。

调整规则：

  • 反应反向，ΔH 变号。
  • 反应系数乘以 n 倍，ΔH 也乘以 n 倍。

例子

已知：

  • C(s)+OX2​(g)​COX2​(g)，ΔH1​=−393.5kJ/mol
  • CO(g)+21​OX2​(g)​COX2​(g)，ΔH2​=−283.0kJ/mol

求：C(s)+21​OX2​(g)​CO(g) 的 ΔH

解法：

目标反应 = 反应1 - 反应2

ΔH=ΔH1​−ΔH2​=−393.5−(−283.0)=−110.5kJ/mol

反应热与键能的关系

反应热本质上来自化学键的断裂与形成。

断键需要吸收能量，成键会释放能量：

ΔH=∑E断键​−∑E成键​

使用条件

  • 已知各化学键的键能数据。
  • 反应物和生成物都是气态（键能是气态分子数据）。
  • 键能是平均值，计算结果是估算值。

例子

计算 HX2​(g)+ClX2​(g)​2HCl(g) 的反应热。

已知键能：

  • H−H：436kJ/mol
  • Cl−Cl：243kJ/mol
  • H−Cl：432kJ/mol

ΔH=(436+243)−2×432=−185kJ/mol

利用燃烧热计算

燃烧热是特定条件下物质完全燃烧的反应热，数据易查且标准化。

可以通过已知物质的燃烧热，结合盖斯定律，推算目标反应的反应热。

方法

  1. 写出反应物和生成物的燃烧反应。
  2. 用盖斯定律组合出目标反应。
  3. 对应的反应热也相应计算。

利用生成热计算

定义

标准生成热 ΔHf∘​：在标准状况下，由最稳定单质生成 1mol 化合物的反应热。

规定：最稳定单质的标准生成热为零。

任意反应的反应热可由生成热计算：

ΔH=∑ΔHf,生成物∘​−∑ΔHf,反应物∘​

为什么这个公式有效

反应可以看作：

  1. 反应物分解为单质（吸收反应物的生成热）。
  2. 单质重新组合成生成物（释放生成物的生成热）。

总热效应 = 生成物生成热之和 - 反应物生成热之和。

优势

  • 数据标准化，查表方便。
  • 适用范围广，不限于气态反应。
  • 计算简洁。
